Trainer: how to add this game
  1. Copy the game's files into the game-05/ folder, replacing this index.html.
  2. Keep the game's own assets/, CSS and JS next to its index.html (relative paths only).
  3. Add <script src="../assets/js/hub-nav.js"></script> before </body> for the back button.
  4. In site-config.js, update the title/description and set ready: true.
