    How to play

    Four steps — no login, nothing to install.

    1. 1

      Choose a game

      Scroll the cards above and pick one that looks fun.

    2. 2

      Unlock it

      Scan the QR code on your instructor’s slide, or click “Play Now” and type the game code shown under it.

    3. 3

      Complete the activity

      Follow the instructions inside the game.

    4. 4

      Come back & try another

      Use “Back to Game Hub” in the corner of every game.

    Use your laptop for the best experience. Phones work too, but the games are made for a bigger screen.

      Change a game code

      Codes are not stored anywhere on this site — only a fingerprint (hash) of each one lives in site-config.js. To set a new code, type it here, then replace that game’s line in access.keys with the result. Old QR codes for that game stop working immediately.
